# 🚀 Muhammad Atif — Personal Developer Portfolio

An ultra-modern, high-performance developer portfolio built with **Next.js 14**, **React 18**, **TypeScript**, and **Tailwind CSS**. Designed with custom soft sage green aesthetic (`#dae6dd`), terracotta highlights (`#c85a28`), interactive Mindmap Skills Tree, and code terminal interfaces.

## ✨ Features & Spec Highlights

- **🎨 Modern Design System**: Built on a curated soft sage green background canvas (`#dae6dd`) paired with warm terracotta accents (`#c85a28`) and dark obsidian terminal windows (`#141816`).
- **🌳 Interactive Skills & Technology Mindmap**:
  - Interactive flowchart tree structure connecting 6 primary engineering domains (**BACKEND**, **FRONTEND**, **AI & LLM**, **AUTOMATION**, **DEVOPS**, **TOOLS**).
  - Hover-activated pop-up cards (`scale-[1.05]`) with instant terracotta highlight color conversion.
  - **0.2 Opacity Blur Filter** applied to unhovered categories for focused exploration with automatic reset on mouse leave.
  - Connected with physical tree branch lines (`├─` / `└─`).
- **💻 `developer.ts` Code Terminal Card**: macOS-inspired code editor card with syntax highlighting, live status indicator (`Open to opportunities`), and interactive floating skill badges.
- **⚡ Moving Tech Stack Ticker**: Continuous horizontal marquee featuring top technologies:
  - React, Next.js, Node.js, TypeScript, MongoDB, Tailwind CSS, PostgreSQL, Git, Adobe Premiere Pro, and After Effects.
- **📱 100% Fully Responsive Layout**: Tailored grid breakpoints for seamless viewing on Desktop, Tablet, and Mobile devices.
- **🎯 Navigation & Smooth Scroll**: Integrated sticky header with active section tracking and smooth scroll (`#home`, `#about`, `#projects`, `#skills`, `#experience`, `#contact`).

## ⚙️ Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/atif00150/Personal-Portfolio.git
   cd Personal-Portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the local development server**:
   ```bash
   npm run dev
   ```

4. Open `http://localhost:3000` in your web browser to view the application live.
